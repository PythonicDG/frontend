# Loopr AI Frontend

Loopr AI is a React + TypeScript dashboard for monitoring financial activity, transaction flows, and account health.

## Features
- Authentication flow for secure access
- Financial overview dashboard with metrics and charting
- Transaction listing, filtering, and pagination
- CSV export workflows for account reporting
- Responsive layout for desktop dashboard use

## Getting started
1. Install dependencies with npm install.
2. Copy .env.example to .env and set your API URL.
3. Start the app with npm run dev.
4. Build for production with npm run build.

## Scripts
- npm run dev
- npm run build
- npm run preview
